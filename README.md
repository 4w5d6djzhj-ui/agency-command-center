# Agency Command Center — demo site

Static build of the Agency Command Center demo (Hakobian Agency edition, golden-ratio layout). Served with GitHub Pages from the `main` branch root.

Two demos live here: the main site at `/` and the v2 fresh design at `/v2/`.

How to rebuild, test and deploy: see [`tools/README.md`](tools/README.md). The build source (`tools/patch/src/`), the patch script and the Playwright suites are in `tools/`.
